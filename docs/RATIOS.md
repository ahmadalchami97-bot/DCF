# Institutional Financial Ratio Analysis Workbook

A 15-sheet, **fully-formula-driven, auditable** Excel workbook dedicated to
financial-ratio analysis — the kind of company study an analyst runs *before*
valuation. Generated by the `ratios/` Python package; the deliverable is the
`.xlsx`.

```
pip install -r requirements.txt
python build_ratios.py                              # -> examples/ratio_analysis.xlsx
python build_ratios.py --blank -o template.xlsx      # empty data-entry template
```

Open in Excel or LibreOffice and start on the **Home** sheet.

---

## Design philosophy

The brief's hard rules, and how this workbook meets them:

* **Simple formulas only — no nested IFs, no mega-formulas.** Every ratio is one
  short, guarded division referencing already-computed cells (e.g.
  `ROE = Net income / Average equity`). Intermediate steps live in their own
  **helper rows** on the Inputs sheet (averages, totals, NOPAT, invested capital,
  EV…). Classifications avoid nested IFs entirely by using a `CHOOSE()` over
  boolean arithmetic:

  ```
  index = 1 + (value>=low) + (value>=high)     ->  1, 2 or 3
  label = CHOOSE(index, "Weak", "Adequate", "Strong")
  ```

* **Fully formula-driven & auditable.** Inputs flow through to every ratio, score
  and chart as live formulas. Nothing is hardcoded in an output cell. You can
  read any ratio without opening Excel's formula auditor.

* **The mandated 4-colour cell scheme.** Yellow = input (editable), blue =
  formula/helper (protected), green = output/result (read-only), red = error/flag.
  Classification cells are coloured green/amber/red by traffic-light conditional
  formatting. A legend on the Home sheet explains it.

* **No modelling errors.** The whole workbook is evaluated by a dependency-free
  Excel-formula engine on every test run: **0 formula errors, 0 circular
  references**; the balance sheet balances to the unit every year; DuPont ROE ties
  to ROE; common-size revenue equals 100%.

## The fifteen sheets

| # | Sheet | Contents |
|---|-------|----------|
| 1 | **Home** | Cover page, company profile (identity inputs), legend, one-click navigation. |
| 2 | **Dashboard** | Six category scores (0–100) with data-bar progress bars + traffic lights, an overall quality score, key-metric trend arrows, headline KPIs and formula-driven observations. |
| 3 | **Inputs** | 10 historical + 5 forecast years of statement data (yellow), computed subtotals (blue), and a reusable **Helper Calculations** block (averages, total/net debt, invested capital, NOPAT, EV, capital employed, tangible book) + a step-by-step WACC. |
| 4 | **Common Size** | Income statement vs revenue, balance sheet vs assets, and indexed horizontal/trend analysis, with heat-maps. |
| 5 | **Profitability** | Margins, ROE/ROA/ROIC/ROCE/Cash ROIC, retention, and a 3-step **DuPont** decomposition (with a built-in tie-out check). |
| 6 | **Liquidity** | Current, quick, cash ratios; working capital; OCF ratio; cash conversion. |
| 7 | **Solvency** | Debt/equity, debt/assets, debt/capital, net debt/EBITDA, interest / EBITDA / debt-service / fixed-charge coverage, equity ratio. |
| 8 | **Efficiency** | Asset/fixed-asset/inventory/receivable/payable/working-capital turnover; DSO/DIO/DPO; cash conversion cycle. |
| 9 | **Growth** | Year-on-year growth for seven metrics + a 3/5/10-year CAGR scorecard. |
| 10 | **Valuation** | Transparent EV bridge, then P/E, forward P/E, PEG, EV/Revenue, EV/EBITDA, EV/EBIT, EV/FCF, P/B, P/TBV, P/FCF, dividend / FCF / earnings yields. |
| 11 | **Capital Allocation** | Payout, dividend growth, buybacks, share-count change, FCF conversion, retention, total payout, and a 0–5 capital-allocation score. |
| 12 | **Quality** | **Piotroski F-Score**, **Altman Z-Score**, **Beneish M-Score**, ROIC vs WACC spread and economic profit — every component shown as a helper row. |
| 13 | **Benchmarking** | Company vs five peers across ten ratios: median, rank, percentile, best-in-class flags, a competitive-profile radar and a peer bar chart. |
| 14 | **Guide** | For every ratio: definition, formula, what it measures, strong/average/weak ranges and the practical investment meaning. |
| 15 | **Quality Control** | Automated validation: balance-sheet integrity, DuPont tie-out, common-size tie-out, missing inputs, zero/negative denominators, outliers, WACC sanity, units — with an overall PASS / REVIEW / FAIL verdict. |

## Visuals

* **Heat-maps** (colour scales) across every ratio row and the CAGR / peer grids.
* **Data bars** for the dashboard score progress bars.
* **Trend arrows** (▲ ► ▼) via a single `CHOOSE()` formula, plus icon-set support.
* **Traffic-light** classifications (green / amber / red) by conditional formatting.
* **Charts**: line (margin/return/turnover trends), bar (peer comparison, CCC) and
  a **radar** (competitive profile vs peer median). All update with the data.

> Excel sparklines are not part of the open `.xlsx` format that openpyxl writes,
> so per-row trend is shown with arrows + heat-maps and per-group trend with
> embedded line charts (a fully formula-/data-driven equivalent).

## How to use

1. Open `examples/ratio_analysis.xlsx` to see the worked example
   (*Vanta Software Group*, a fictional software compounder), or start from the
   blank template.
2. On **Home**, fill the company profile (yellow cells).
3. On **Inputs**, replace the yellow cells with the company's figures — at least
   revenue, equity, assets and shares; the more you supply, the deeper the
   analysis. Leave unknowns blank (the model marks them missing and continues).
4. Enter the cost-of-capital assumptions (for ROIC vs WACC) and peer ratios on
   **Benchmarking**.
5. Read the **Dashboard**; drill into any ratio family; check **Quality Control**
   for flags and the **Guide** for interpretation help.

Conventions (stated on the sheets): operating expenses are entered **ex-D&A**
(EBITDA = gross profit − opex; EBIT = EBITDA − depreciation); capex, dividends and
buybacks are positive amounts.

## Architecture

```
build_ratios.py        CLI entry point
ratios/
  config.py            palette + 4-colour scheme, classification bands, guide content
  style.py             the 4-colour cell roles + institutional headers
  formulas.py          simple, guarded formula builders + CHOOSE-based classifiers
  common.py            build context, drawing chrome, traffic-lights/data-bars/charts
  render.py            Grid — the reusable ratio-row renderer (ratio + arrow + read + heat)
  sample_data.py       worked example (articulated 16-year roll-forward)
  workbook.py          orchestrator (dependency-ordered build, tab colours, print setup)
  sheets/*             one module per sheet
```

Reuses `dcf/utils.py` (the cross-sheet cell registry + styled `Sheet` wrapper).
Sheets are built in dependency order (Home → Inputs → ratio sheets → Quality →
Benchmarking → Guide → Quality Control → Dashboard) so every cross-sheet formula
resolves; they display in reading order.

## Scores — how they are built (all from explicit helper rows)

* **Piotroski F (0–9):** nine binary signals (ROA>0, CFO>0, ΔROA>0, CFO>NI,
  lower leverage, higher current ratio, no dilution, higher gross margin, higher
  asset turnover), summed.
* **Altman Z:** `1.2·X1 + 1.4·X2 + 3.3·X3 + 0.6·X4 + 1.0·X5` (working capital,
  retained earnings, EBIT, market equity/liabilities, sales — each ÷ assets).
  Safe > 2.99, grey 1.81–2.99, distress < 1.81.
* **Beneish M:** the eight-variable model (DSRI, GMI, AQI, SGI, DEPI, SGAI, LVGI,
  TATA). Above −1.78 flags possible earnings manipulation.
* **Dashboard category scores (0–100):** each is the average of a few
  `MIN(ratio / target, 1)` sub-scores ×100 — simple, capped, no nested IFs.

## Verification

```
python tests/test_ratios.py        # 10/10 passing
```

The suite evaluates all ~3,200 formulas (no Excel needed), checks for zero
errors/cycles, asserts the balance sheet balances exactly, the DuPont and
common-size tie-outs hold, the scores are finite and sane, benchmarking ranks the
company, and the blank template degrades gracefully (no errors; QC flags the gaps).
Selected ratios are cross-checked against values recomputed directly from the
sample series.

## Limitations

* Garbage in, garbage out — review the cost-of-capital and peer inputs for your
  own view; with no inputs the workbook stays error-free but Quality Control
  returns FAIL until data is entered.
* Navigation uses hyperlinks styled as buttons (no VBA), so the file stays a
  portable, macro-free `.xlsx`.
* Sheet protection attributes are set per cell (inputs unlocked); enable
  *Review → Protect Sheet* (no password) if you want to lock the formulas.
* Fixed-charge and debt-service coverage are proxies (no lease/principal-schedule
  input); the Guide notes the definitions used.
